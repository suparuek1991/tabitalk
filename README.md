# TabiTalk — วิธีติดตั้งบน iPhone (ใช้เวลาประมาณ 15 นาที)

## 1) ขอ Gemini API key (ฟรี)
1. เข้า https://aistudio.google.com ด้วยบัญชี Google
2. กด **Get API key** → **Create API key** → คัดลอกเก็บไว้ (ขึ้นต้นด้วย `AIza...`)

## 2) เอาแอปขึ้นเว็บด้วย GitHub Pages (ฟรี)
1. สมัคร/ล็อกอิน https://github.com
2. กด **New repository** → ตั้งชื่อ เช่น `tabitalk` → เลือก **Public** → Create
3. กด **uploading an existing file** → ลากไฟล์ทั้ง 6 ไฟล์ขึ้นไป
   `index.html, manifest.json, sw.js, icon-180.png, icon-192.png, icon-512.png` → Commit
4. ไปที่ **Settings → Pages** → Source: *Deploy from a branch* → Branch: `main` / `(root)` → Save
5. รอ 1–2 นาที จะได้ลิงก์ เช่น `https://ชื่อคุณ.github.io/tabitalk/`

> ต้องเป็นลิงก์ https เท่านั้น ไมโครโฟนกับกล้องถึงจะทำงาน

## 3) ติดตั้งบน iPhone (ทำทั้งเครื่องคุณและเครื่องภรรยา)
1. เปิดลิงก์ด้วย **Safari**
2. กดปุ่มแชร์ ⬆️ → **เพิ่มไปยังหน้าจอโฮม (Add to Home Screen)**
3. เปิดแอป TabiTalk จากหน้าโฮม → แท็บ ⚙️ → วาง API key → บันทึก (ต้องขึ้นว่า "เชื่อมต่อสำเร็จ")
4. แตะ 🎤 ครั้งแรก → กด **อนุญาต** ไมโครโฟน
5. ถ้าเสียงญี่ปุ่นไม่ออก: ตั้งค่า iPhone → การช่วยการเข้าถึง → เนื้อหาที่พูด → เสียง → ภาษาญี่ปุ่น → ดาวน์โหลดเสียง (เช่น Kyoko)

## การใช้งาน
- **🗣️ สนทนา**: วางมือถือระหว่างเรากับคนญี่ปุ่น ครึ่งบนกลับหัวให้เขาอ่าน แตะ 🎤 ฝั่งตัวเองเพื่อพูด แตะอีกครั้งเพื่อหยุด แล้วแอปจะแปลและพูดให้ ปุ่มกลางใช้สลับคู่สนทนาเป็นญี่ปุ่นหรืออังกฤษ
- **📷 กล้อง**: เลือกโหมด (ป้าย / เมนูอาหาร / ฉลากสินค้า-ยา) → ถ่ายรูป
- **⭐ วลีด่วน**: ใช้ได้แม้ไม่มีเน็ต แตะข้อความเพื่อขยายเต็มจอให้พนักงานอ่าน
- **⚙️ ตั้งค่า**: API key, โมเดล และประวัติการแปล

## หมายเหตุ
- โหมดสนทนาและกล้องต้องใช้เน็ต ส่วนวลีด่วนไม่ต้อง
- API key เก็บอยู่ในเครื่องเท่านั้น ห้ามส่งลิงก์ที่มี key ให้คนอื่น และอย่าใส่ key ลงในไฟล์บน GitHub
- ถ้าโมเดลเลิกใช้ในอนาคต ให้เปลี่ยนชื่อโมเดลในหน้า ⚙️ ได้เลย
